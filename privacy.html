ULA Factory

Политика конфиденциальности

Действует с 7 октября 2026 года

1. Что это за сервис

ULA Factory — онлайн-сервис для байеров (агентов), которые закупают товары в Китае: учёт заказов, клиентов и доставки. Сайт: miradio5555-code.github.io/robott.

2. Какие данные мы собираем

  • Байеры: имя, телефон, электронная почта, пароль (хранится только в зашифрованном виде), название кабинета. При входе через Google — имя и почта из аккаунта Google.
  • Данные, которые байер вносит сам: заказы, товары, цены, поставщики, фото, комментарии.
  • Клиенты байера (по ссылке на заказ): ФИО, телефон, Telegram (по желанию), город, адрес или пункт выдачи.

3. Зачем

Только для работы сервиса: учёт заказов, связь с клиентом, доставка. Мы не продаём данные и не используем их для рекламы.

4. Кто видит данные

  • Каждый байер видит только свой кабинет. Другие байеры его данные не видят.
  • Клиент по ссылке видит только свой заказ: статус, фото, сумму к оплате и оплату.
  • Администратор платформы имеет доступ к данным кабинетов для технической поддержки и безопасности (только просмотр).

5. Где хранятся данные и кто помогает обрабатывать

  • Данные хранятся в базе данных Supabase с защитой доступа на уровне строк.
  • Сайт размещён на GitHub Pages.
  • Вход через Google обрабатывает Google.
  • ИИ-помощник администратора использует Google Gemini: туда передаются только общие цифры по платформе (количество заказов, суммы, статусы). Имена, телефоны и адреса клиентов не передаются.

6. Ваши права

Вы можете попросить показать, исправить или удалить ваши данные. Байер может изменить свои данные в настройках кабинета, клиент — на странице своего заказа. По остальным вопросам пишите: miradio.5555@gmail.com.

Privacy Policy

Effective October 7, 2026

1. The service

ULA Factory is an online tool for buyers (agents) who purchase goods in China: tracking orders, clients and shipping.

2. Data we collect

  • Buyers: name, phone, email, password (stored only in hashed form), workspace name. With Google sign-in — the name and email from the Google account.
  • Data buyers enter: orders, products, prices, suppliers, photos, comments.
  • Buyers' clients (via the order link): full name, phone, Telegram (optional), city, address or pickup point.

3. Why

Only to run the service: order tracking, contacting clients, delivery. We do not sell data or use it for advertising.

4. Who can see the data

  • Each buyer sees only their own workspace. Other buyers cannot see it.
  • A client with an order link sees only that order: status, photos, amount due and payments.
  • The platform administrator can view workspace data for technical support and security (read-only).

5. Storage and processors

  • Data is stored in a Supabase database with row-level access control.
  • The website is hosted on GitHub Pages.
  • Google sign-in is handled by Google.
  • The administrator's AI assistant uses Google Gemini and receives only aggregated platform figures (order counts, totals, statuses). Client names, phones and addresses are not sent.

6. Your rights

You can ask to access, correct or delete your data. Contact: miradio.5555@gmail.com.
