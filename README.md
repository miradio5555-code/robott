# Cargo China — учёт заказов

Система учёта заказов для закупок в Китае. Работает на GitHub Pages, данные хранятся в Supabase.

## Что внутри

| Файл | Для чего |
|---|---|
| `index.html` | Страница сайта: вход, админка, страница клиента |
| `style.css` | Оформление |
| `app.js` | Вся логика |
| `i18n.js` | Переводы Русский / 中文 |
| `config.js` | **Настройки: сюда вставляются адрес Supabase и ключ** |
| `supabase.js` | Библиотека Supabase (не редактировать) |
| `supabase_schema.sql` | Таблицы и защита базы (запускается один раз в Supabase) |

## Как это работает

- Ты входишь по почте и паролю и управляешь заказами.
- Для каждого заказа создаётся ссылка вида `https://ИМЯ.github.io/cargo-china/?order=токен`.
- По этой ссылке клиент видит только свой заказ, без возможности что-то менять.
- Клиенту не показываются: поставщик, ссылка 1688, цена в ¥, курс, телефон, WeChat и внутренний комментарий.

## Расчёты

- Стоимость товара, ¥ = количество × цена за единицу
- В сомах = стоимость товара × курс
- Итого = в сомах + доставка
- Остаток = итого − оплачено

В сводке на главной суммы считаются без отменённых заказов. Задолженность — сумма положительных остатков.

## Безопасность

- Ключ `anon` / `publishable` в `config.js` публичный, это нормально: доступ к данным закрыт правилами Row Level Security.
- Ключ `secret` / `service_role` вставлять в проект **нельзя**.
- Доступ к админке есть только у пользователей из таблицы `admins`.
- После создания своего аккаунта отключи регистрацию: Supabase → Authentication → Sign In / Providers → выключить **Allow new users to sign up**.
- Фото лежат в публичной папке с непредсказуемыми именами. Загружать и удалять их может только администратор.

## Если что-то не работает

- Белый экран «Нужно заполнить config.js» — проверь адрес и ключ в `config.js`.
- «Неверная почта или пароль» — проверь пользователя в Supabase → Authentication → Users.
- «У этого аккаунта нет доступа» — пользователь не добавлен в таблицу `admins`.
- Сайт не открывается из Китая — попробуй VPN. GitHub Pages и Supabase иногда работают нестабильно.
